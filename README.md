# Pillalú Manager

Herramienta propia de **Pillalú** (dropshipping, Colombia, COP) para reducir el trabajo manual de
importar, seleccionar, valorar y publicar productos de **Dropi** en **Mercado Libre Colombia** y
**Facebook Marketplace**.

> Estado: **Fase 0 — investigación de viabilidad técnica.** Todavía no hay código ejecutable.

## Objetivo

Generar ganancias vendiendo productos de Dropi con el mínimo trabajo manual posible:

1. Importar productos, imágenes, precios, proveedores e inventarios desde Dropi.
2. Identificar productos con potencial comercial.
3. Calcular precio de venta, costos, comisiones y margen.
4. Generar títulos y descripciones con IA.
5. Publicar en los canales mediante mecanismos **autorizados**.
6. Sincronizar precios e inventarios.
7. Gestionar pedidos, devoluciones y ganancias.
8. Mostrar indicadores en un dashboard.

## Reglas del proyecto

- Solo APIs oficiales y mecanismos autorizados. Nada de scraping no autorizado ni evasión de restricciones.
- Ninguna publicación, pedido real o gasto sin autorización explícita del fundador.
- Ningún secreto en el repositorio (ver `docs/SECURITY.md`).
- Trabajo por ramas y pull requests; cada PR pasa auditoría antes de fusionarse.
- Rentabilidad por encima de complejidad tecnológica.
